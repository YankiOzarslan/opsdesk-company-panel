# Contributing

1. Use Node.js 20+ and `npm ci --ignore-scripts`.
2. Create a branch for a focused change.
3. Use synthetic fixtures and temporary databases; never copy production records.
4. Run `npm run check:share`, `npm test` and `npm audit --omit=dev`.
5. Describe the behavior change, validation and relevant limitations in your pull request.

No contribution license or open-source license has been selected yet. Discuss intended reuse with the repository owner.
